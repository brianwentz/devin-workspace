# Devin Workspaces — project rules

Electron desktop client for Devin (BaseWindow + WebContentsViews; the React shell is the only view exposing a window API via preload).

## Commands
- `npm run typecheck` — `tsc --noEmit`
- `npm run test:unit` — vitest, `tests/unit` (pure logic only)
- `npm run build` — esbuild (main/preload/scripts → `out/*.cjs`) + `vite build` (shell → `out/shell`)
- `npm run test:e2e` — build + Playwright `_electron` (`tests/e2e`, fixture servers in `tests/fixtures/http.ts`)
- `npm run dist:win` — build + electron-builder NSIS per-user x64 installer → `dist/DevinWorkspaces-Setup-<version>.exe` (unsigned, fuses flipped by electron-builder from `build.electronFuses`; `scripts/after-pack.cjs` only writes `resources/signing.json`; icon from `build/icon.ico` via `npm run icon`)
- `npm run dist:mac` — build + electron-builder arm64 dmg+zip → `dist/DevinWorkspaces-<version>-arm64.*` + `latest-mac.yml`; ad-hoc signed (`-c.mac.identity=- -c.mac.hardenedRuntime=false` — hardened runtime off because ad-hoc signatures have no team ID), so Gatekeeper requires right-click → Open on first launch (icon from `build/icon.png`, entitlements `build/entitlements.mac.plist`). Never reintroduce fuse-flipping in afterPack — it invalidates the Electron ad-hoc signature → "application is damaged".
- `npm run smoke:install` — `scripts/smoke-install.ps1`: silent install → `tests/smoke/installed.spec.ts` (CDP-driven, `playwright.smoke.config.ts`) → upgrade-in-place → uninstall; evidence in `docs/evidence/p3-smoke*` (docs/ is git-ignored - local output only). Run before pushing when packaging or the settings schema changes (it reads `settings.json` directly).
- `npm start` / `npm run acp:probe`
- CI: `.github/workflows/windows.yml` (push/PR: typecheck, unit, build, e2e, dist:win, smoke:install, plus a `macos` job running typecheck/unit/build/dist:mac only — e2e and smoke stay Windows-only); `release.yml` (on `release: published` with tag `vX.Y.Z` created in the GitHub UI: sets package.json to X.Y.Z, builds Windows + macOS arm64, uploads `.exe`/`.blockmap`/`.dmg`/`.zip`/`latest.yml`/`latest-mac.yml` to that release — the feed used by `src/main/updater.ts` — then commits `chore: release vX.Y.Z` to main; never bump the version by hand; mark a release as pre-release to keep clients from auto-updating to it; macOS signing/notarization is optional via secrets `CSC_LINK`, `CSC_KEY_PASSWORD`, `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID` — unsigned Mac builds have the updater disabled: `updater-disabled reason: unsigned-mac`, gated by `resources/signing.json` written by after-pack)

## Env vars
`DEVIN_WORKSPACES_TEST=1` enables `__devinworkspaces` hooks; `DEVIN_WORKSPACES_TENANT_URL` (overrides settings.tenantUrl); `DEVIN_WORKSPACES_USER_DATA` (default userData is `%APPDATA%\devin-workspaces` (from package.json `name`)), `DEVIN_WORKSPACES_LOG`, `DEVIN_WORKSPACES_DOWNLOAD_DIR`, `DEVIN_WORKSPACES_SCALE`, `DEVIN_WORKSPACES_ALLOW_EXTERNAL` (test override for `settings.routing.allowExternal`), `DEVIN_WORKSPACES_TEST_GITHUB_ORIGINS` (comma-separated), `DEVIN_WORKSPACES_TEST_BEFOREUNLOAD`, `DEVIN_WORKSPACES_TEST_WINDOW_SIZE` (`WxH`, default `1400x900` — CI runners with small displays get a fail-fast error instead of pane timeouts), `DEVIN_WORKSPACES_TEST_KEEPALIVE_MS` (test override for `settings.tabs.keepAliveHours`; 0 = discard hidden-scope tabs on switch), `DEVIN_WORKSPACES_LOG_MAX_BYTES` (test-only event-log rotation cap, default 10 MB). Smoke only: `DEVIN_WORKSPACES_INSTALLED_EXE`, `DEVIN_WORKSPACES_SMOKE_PROFILE`, `DEVIN_WORKSPACES_SMOKE_PHASE` (`fresh`|`upgrade`), `DEVIN_WORKSPACES_SMOKE_EVIDENCE`. `DEVIN_WORKSPACES_TEST=1` also disables the auto-updater. `DEVIN_WORKSPACES_EVIDENCE=1` makes the routing e2e write its event log to `docs/evidence/e2e-fixture-events.jsonl` (default: temp profile; docs/ is git-ignored).
P5 (test mode only): `DEVIN_WORKSPACES_API_BASE` (overrides `settings.apiBase` for the v3 poller), `DEVIN_WORKSPACES_POLL_MS` (poll interval for active and idle), `DEVIN_WORKSPACES_TEST_BANNER_MS` (shortens the notification banner's 8 s auto-hide), `DEVIN_WORKSPACES_TEST_AUTOFILL_PROMPT_MS` (shortens the save-password prompt's 1.5 s show-delay fallback), `DEVIN_WORKSPACES_TEST_AUTOFILL_DISMISS_MS` (shortens its 10 s auto-dismiss).
- `npm run acp:contract` — P4 contract run against the real `devin acp` (initialize/new/prompt/cancel/list/load); writes `docs/evidence/p4-acp-contract.jsonl` (git-ignored); exit 0 also when the CLI is missing/unauthenticated (reported in the file)
`DEVIN_WORKSPACES_TEST_AUTH_STATUS_CMD` (test mode only, e.g. `node out/fixtures/fakeAuthStatus.cjs`) replaces the `devin auth status` spawn used for service-user identity resolution; the fake reads `FAKE_AUTH_STATUS_EXIT` / `FAKE_AUTH_STATUS_USER_ID` / `FAKE_AUTH_STATUS_ORG_ID`.
`DEVIN_WORKSPACES_LOCAL_AGENT_CMD` (test mode only, e.g. `node out/fixtures/fakeAcpAgent.cjs`) replaces the `devin acp` spawn with a full command; the fake agent reads `FAKE_ACP_LIST=1` / `FAKE_ACP_LOAD=1` / `FAKE_ACP_DELETE=1` / `FAKE_ACP_LINK_URL`. `DEVIN_CLI` overrides the binary for `acp:probe` / `acp:contract`.
`DEVIN_WORKSPACES_TEST_TERMINAL_CMD` (test mode only, e.g. `node out/fixtures/fakePty.cjs`) replaces the command the embedded terminal spawns — for both `devin`-kind (Local panel) and `shell`-kind (dock) ptys.

## Versions
Requires Node ≥ 22.12; currently developed on Node 24.x. All deps are pinned exact — package.json is the source of truth.

## Layout & settings (F-features)
- Frame: `titleBarStyle: 'hidden'` + `titleBarOverlay` on the BaseWindow, `Menu.setApplicationMenu(null)`; the shell's `TitleBar.tsx` renders the drag region and the GitHub tab strip. Zoom (Ctrl+= / Ctrl+- / Ctrl+0) and detached DevTools (F12 / Ctrl+Shift+I, dev only) live in `src/main/shortcuts.ts`; Ctrl+` toggles the terminal dock.
- Settings keys: `pane.open` + `pane.fraction` (0..1 share of the available width — px guards are derived in `computeBounds`, never persisted; `pane.width` migrates to fraction on load), `windowPlacements` (per-display-config window bounds/maximized), `layout.terminalOpen`/`layout.terminalHeight`, `terminal.allSurfaces` (show the dock on Local/Settings too), `prs.autoOpenTabs` (lazy background tab when a session gains a PR), `notifications.userId` (manual user-id override for service-user tokens; `''` = detect automatically).
- Shell right-click gets a native menu from `src/main/contextMenu.ts` (`context-menu` log event: editable/hasSelection/hasLink booleans only); xterm containers have their own copy/paste context menu. Test hooks `clipboardWrite`/`clipboardRead` wrap Electron's clipboard.
- Pane toggle resizes the WINDOW, not the split: `setPaneOpen(open, source)` in `src/main/window.ts` is the single seam (rail, Ctrl+Shift+G, settings:set, test hooks, tab auto-open). Closing shrinks the window so the devin column keeps its exact px width; opening grows to the right where the pane px derives from `pane.fraction` as f/(1−f)·devin (fraction clamped to 0.95 for the ratio), capped at the display work area and never shrinking. `paneToggleWindowWidth` in `src/core/layout.ts` computes the target (`computeBounds` unchanged); maximised/fullscreen keeps the in-window split. The window min width is dynamic: 696 closed / 1000 open (`applyMinimumSize`, applied before the shrink / after the grow). `pane-toggle` log detail: `{ paneOpen, source, resized, fromWidth, toWidth, maximized }`.
- Removed channels: `pane:width` (width changes come from the splitter drag or `paneFraction` in ShellState); `tabs:scopeMenu` (the "N in other sessions" overflow button was removed — hidden scopes are still in `ShellState.tabs.hiddenTabCount`).
- New log events: `window-placement`, `pr-auto-open`, `pr-open`, `pr-menu`, `pr-title`, `notifier-self`, `terminal-toggle` (plus existing `drag-*` events now carry `axis`); service-user identity: `identity-resolve`, `identity-rejected`, `identity-observe`, `identity-observe-error`, `identity-reset`, `identity-save-error`, `notifier-org-mismatch` (booleans/counts/durations only — never the user id).

## Conventions
- `src/core/` is pure TS — no `electron` imports (unit-testable).
- All IPC payloads are validated with the zod schemas in `src/shared/ipc.ts`; add a schema when adding a channel.
- IPC handlers go through `ipcGuard` (`guardedHandle`/`guardedOn`) — shell sender only.
- Log URLs/ids/lengths only — never page or process output text (terminal output, ACP stderr, credential usernames/passwords are all excluded).
- `tenantUrl`/`apiBase` must be https (localhost http only in tests via `DEVIN_WORKSPACES_TENANT_URL`).
- Remote views (devin + `gh:*` tabs) get only `out/autofill-preload.cjs` (`src/autofill/preload.ts`): sandbox + contextIsolation stay on, it exposes nothing via contextBridge, and it talks to main only over `autofill:*` channels guarded by `hostedHandle`/`hostedOn` (`fromHostedView`: sender is a hosted view, frame origin == top-frame origin). Partitions stay separate.
- Shell loads only `app://shell/...`; strict CSP — `script-src 'self'`, no inline script; `style-src` allows `'unsafe-inline'` only because xterm.js injects `<style>` elements (P4b) — keep all other directives unchanged.
- Explicit `webContents.close()` on tab/window teardown; keep the splitter z-order-raise drag protocol intact.
- Secrets (vault passwords) never reach renderers or logs; credential IPC handlers must not log payloads.
- Passwords (autofill): `credentials.json` v2 is id-keyed with many accounts per origin (v1 migrates on load) in `src/main/credentials.ts`; login-form heuristics live in `src/core/autofillModel.ts`; main side is `src/main/autofill.ts`; shell overlays `AccountPicker.tsx` / `SavePasswordBanner.tsx` are raised via `overlayOpen()` in `window.ts`. One account → fill on load (never submits); several → account picker on field focus; a submitted login → save/update prompt after the next navigation or 1.5 s, auto-dismissed after 10 s. Log events: `autofill-query`, `autofill-picker`, `autofill-capture`, `autofill-prompt`, `autofill-save`, `autofill-save-failed`, `autofill-dismiss`, `credential-add|update|delete|reveal` — origins/counts only. Removed channels: `credentials:fill`, `credentials:menu`.
- The Devin API token lives only in `src/main/secrets.ts` (safeStorage-encrypted `userData/secrets.json`) and main-process memory: never add it to `ShellState`, IPC replies, or `log()` calls. Scrub error strings with `sanitizeMessage`.
- `tabs-preload` event: on scope switch/launch the visible scope's discarded tabs are background-loaded (150 ms stagger); the live cap (`tabs.maxLiveTabs`) and idle discard apply to hidden scopes only — the visible scope's tabs are exempt.
- P6 notification center: `src/core/notificationModel.ts` (derive/list ops, pure) + `src/main/notifications.ts` (persisted store in `notifications.json`; 'update' entries are runtime-only). IPC: `notifications:list|markRead|markAllRead|remove|clear|open|panel|identity|identityReset`, push `notifications:banner`. While the panel is open main raises the shell view (`setNotificationsPanel`/`raiseShell`); the raise must survive `applyLayout` and surface switches close it. Taskbar overlay = unread count (`badge` log event); no OS toasts. Entries carry `ownerUserId`; `NotificationStore.reconcile(userId)` runs once per `/v3/self` resolution and prunes session-scoped entries from other users / legacy builds (`notifications-pruned` log event, counts only); the `identity` kind is runtime-only like `update` and is raised once for service-user tokens.
- App version + update status: `ShellState.update` = `{ version (app.getVersion()), available, downloaded }` from `src/main/updater.ts`; Settings renders it in `#aboutSection` (`#appVersion`, `#updateStatus[data-update-state=none|downloading|ready]`, `#updateNow`). `update:install` (shell-only, no payload) calls `installUpdate()` only when a download is ready. Test hooks: `simulateUpdateAvailable` / `simulateUpdateDownloaded`.
- The v3 poller only lists the token user's sessions: `notifier` always calls `GET /v3/self` (org-id override still wins) and passes `user_ids` to the sessions list. A PAT's `user_id` comes straight from `/v3/self` (source `self`); for a service-user token the user id is resolved by `src/main/identity.ts` (`identity.json` in userData persists cli/inferred results) in the order manual → `devin auth status` → persisted → inferred-from-observed-sessions (`onSessionChanged` in `src/main/sessions.ts` calls `getSession` and feeds `src/core/identityModel.ts` vote logic), retried each poll while unresolved. The first filtered `listSessions` after a cli/inferred resolution must confirm the id (a matching session or an empty single page) — otherwise the source is rejected for that generation and the next strategy runs. Fully unresolved → `state.notifications.noUserIdentity` and an `identity` notification; `state.notifications.identity = { source, resolved }` never carries the id (the shell reads `{ source, maskedUserId, cliOrgMismatch }` via `notifications:identity`; `notifications:identityReset` clears it). `notifications.openPrCount` (was `currentSessionPrCount`) counts open PRs across those sessions; `src/main/prTitles.ts` resolves GitHub PR titles via `ses.fetch` on `persist:github` (10 min null / 6 h ok cache, 3 concurrent, `pr-title` log event — never the title text); `src/core/prTitle.ts` parses/strips the `<title>` (pure).
- Devin Local (`src/main/local/`, `src/shell/local/`, reducers in `src/core/localModel.ts`): spawn the external `devin` binary (`acp`), never fork Node (RunAsNode fuse is off). Gate `session/list` / `session/load` / `session/delete` on `agentCapabilities.sessionCapabilities.list` / `agentCapabilities.loadSession` / `agentCapabilities.sessionCapabilities.delete` (`local:session:delete` channel; `session-delete` log event; deleting a running session is refused — cancel first). Log prompt/message lengths and ids, never content. `src/core/prLinks.ts` (`stripAnsi`, `extractPullRequestUrls`, `LinkScanner`) scans agent chat output (acpHost via injected `onPullRequestUrl` — never user chunks) and devin-pty output (terminalHost `flush`); a new PR URL calls `src/main/local/prAutoOpen.ts` `autoOpenLocalPr` → lazy background tab in `local:<sessionId>` gated on `prs.autoOpenTabs`, `pr-auto-open` event with `detail.source` = `local-chat|local-terminal`. xterm uses `@xterm/addon-web-links` (plain-click → `localOpenLink`). Devin-kind ptys are per-session (`bySession` map, `TerminalSummary.sessionId`, `terminalOpen` takes `{ kind:'devin', workspace, sessionId }`; `closeForSession`/`closeForWorkspace` on delete/workspace removal). The GitHub tab scope for Local is `local:<sessionId>` via `localScope`/`effectiveScope` in `src/core/tabModel.ts` — `syncScope()` runs at the top of `applyLayout`; the selected local session is lifted to `state.localSessionId` via the `local:activeSession` channel (`active-session` log event) and mirrored in `ShellState.localSessionId` so it survives surface switches; delete also `closeScope`s the session's tabs.
- P4b terminal: `node-pty` is N-API, so its win32-x64 prebuild works in Electron without a rebuild — no postinstall; `npm run rebuild:native` (electron-builder install-app-deps) exists if a rebuild is ever needed (requires MSVC). node-pty is esbuild-external + `asarUnpack`ed and `build.files`-listed. Terminal output is never logged (byte counts only). devin-kind ptys get `WT_SESSION`/`TERM_PROGRAM` when unset so the `devin` CLI doesn't detect conhost (`terminal-env` carries `added: [...]`). On quit, `dispose()` taskkills the child tree before `proc.kill()` — ConPTY teardown on a live console deadlocks the libuv loop (`terminal-dispose-error`/`terminal-dispose-failed` if teardown still misbehaves).
- `window.devinworkspaces.platform` (a static `process.platform` string exposed by the preload) is the only platform signal in the shell — no IPC needed.
